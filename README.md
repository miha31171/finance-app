# 💼 Мои финансы — локальное приложение для личных финансов и инвестиций

Полностью локальное веб‑приложение: без сервера, без регистрации, без телеметрии. Все ваши данные (счета, операции, портфель) хранятся **только в вашем браузере** (localStorage).

## Как открыть
1. Распакуйте архив `finance-app.zip`.
2. Дважды щёлкните `index.html` — откроется в браузере (Chrome, Firefox, Edge, Safari).
3. Альтернатива (если браузер ограничивает file://):
   ```
   cd finance-app
   python3 -m http.server 8000
   ```
   и откройте http://localhost:8000
4. Нажмите «Импорт → Загрузить демо-данные», чтобы посмотреть на вымышленном примере. Удалить демо: «Настройки → Удалить только демо».

> Данные привязаны к браузеру и способу открытия (file:// и http://localhost — разные хранилища). Регулярно делайте «Настройки → Экспорт в JSON».

## Возможности
**Личные финансы**
- Импорт выписок: CSV (Сбер, Т‑Банк/Тинькофф, Альфа и др.; разделитель `;` или `,` определяется автоматически; кодировки UTF‑8 и Windows‑1251), OFX/QFX, простой JSON (`[{date, amount, currency, description, category}]`). Дубликаты пропускаются.
- Несколько счетов/кошельков: банк, наличные, крипто, брокерский; начальный баланс или ручной баланс.
- Ручное добавление/редактирование/удаление операций, поиск и фильтры.
- Обзор: балансы по валютам, итог в ₽ по ручным курсам (или кнопка «курсы ЦБ»), доходы/расходы за этот и прошлый месяц, график по месяцам, топ категорий.
- Автокатегоризация по ключевым словам (редактируется в «Настройках»).
- Резервная копия JSON, восстановление, удаление всех данных.

**Инвестиции** (вкладки «Рынок», «Портфель», «Прогноз», «Идеи и рекомендации»)
- Живые публичные котировки по кнопке «Обновить котировки»: MOEX ISS (акции, БПИФ, ОФЗ, индекс IMOEX), ЦБ РФ (cbr-xml-daily.ru), CoinGecko (крипто в ₽). При сбое — последний кэш; можно импортировать цены вручную CSV `дата;тикер;цена` (пример: `samples/ПРИМЕР_prices.csv`).
- Портфель: акции, фонды, ОФЗ (по SECID/ISIN, напр. `SU26238RMFS4`), крипто (id CoinGecko, напр. `bitcoin`), кэш/вклады. Стоимость, P&L, распределение.
- Аналитика: доходность, волатильность, макс. просадка, моментум 1/3/6/12 мес., SMA50/SMA200.
- Прогноз Монте‑Карло (3000 сценариев, ежемесячные взносы) с коридорами 25–75% и 5–95%; формулы показаны в интерфейсе.
- Рекомендации по прозрачным правилам: анкета риск‑профиля, подушка безопасности, норма сбережений и сумма для ежемесячных инвестиций из данных о доходах/расходах, концентрация, ребалансировка к шаблону профиля, скринер идей (акции, БПИФ, ОФЗ, крипто) с баллом и пояснением «почему в списке».

> ⚠️ **Инвестиционный раздел — образовательная аналитика, не индивидуальная инвестиционная рекомендация.** Прогнозы — статистические модели, а не гарантии. Прошлая доходность не гарантирует будущую.

## Как выгрузить выписку из банка
Названия пунктов меню меняются; общий принцип такой:
- **Сбербанк (СберБанк Онлайн, веб‑версия)**: Счёт/карта → «Выписки и справки» → выписка за период. Если доступен только PDF — используйте CSV/Excel, где он есть (Excel сохраните как «CSV (разделители — точка с запятой)»).
- **Т‑Банк (Тинькофф)**: веб‑версия → «Операции» → выберите период → «Выгрузить» → CSV (или OFX).
- **Альфа‑Банк**: Альфа‑Онлайн (веб) → Счёт → «Выписка» → формат CSV/Excel (или 1С/OFX, если есть).
- **Другие банки**: ищите выгрузку в CSV, Excel (сохраните как CSV), OFX/QFX. Нужны колонки «Дата» и «Сумма» (или «Приход»/«Расход»); «Описание», «Категория», «Валюта» — по желанию.

## Конфиденциальность
- Выписки и все данные обрабатываются только в браузере; никуда не загружаются.
- Нет аналитики, трекеров, CDN и внешних библиотек — весь код в этой папке.
- Сетевые запросы делаются **только** по вашему нажатию («Обновить котировки», «Курсы ЦБ») и только к публичным адресам: `iss.moex.com`, `www.cbr-xml-daily.ru`, `api.coingecko.com`. В запросах — только тикеры из общего списка/вашего портфеля (без количеств, сумм и данных о вас), без cookies и referrer. Другие адреса запрещены политикой безопасности (CSP) в `index.html`.
- Кнопка «Удалить все данные» стирает всё из хранилища браузера.

## Файлы
- `index.html`, `app.css` — интерфейс; `core.js` — парсеры и математика (общий для браузера и тестов); `app.js` — личные финансы; `invest.js` — инвестиции; `charts.js` — графики SVG; `demo.js` — демо‑данные.
- `samples/` — **ПРИМЕРЫ с вымышленными данными**: `ПРИМЕР_sber.csv` (cp1251, `;`), `ПРИМЕР_tbank.csv` (UTF‑8, `;`), `ПРИМЕР_alfa.csv` (`,`, Приход/Расход), `ПРИМЕР_usd.ofx`, `ПРИМЕР_simple.json`, `ПРИМЕР_prices.csv`.
- `tests/test.js` — тесты: `node tests/test.js` (офлайн) или `node tests/test.js --live` (плюс проверка публичных API). `tests/smoke.html` — проверка в браузере.

## Ограничения
- Форматы банков меняются; если CSV не распознан, переименуйте заголовки в «Дата», «Сумма», «Описание».
- Нет автоконвертации валют операций; итог в ₽ — по ручным курсам.
- Дивиденды в бесплатном ISS API не доступны и в скринере не учитываются. Котировки MOEX могут идти с задержкой.
- История ~1 год — статистика короткая; прогноз не учитывает инфляцию, налоги, комиссии и «толстые хвосты».
- Список инструментов скринера фиксирован в `invest.js` (UNIVERSE) — его легко расширить.
